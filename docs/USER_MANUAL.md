# FG Event Platform 取扱説明書

FORMULA GYMKHANA 学生参加プラットフォームの使い方を、利用者のタイプ別にまとめたものです。
本番URLは `https://formulagymkhana.github.io/fg-event-platform/app/` を基点とし、各ページは `app/<ページ名>.html` の形で配信されます。

対象者は以下の4タイプに分かれます。自分の役割に該当する章を参照してください。事前登録した学生（選手・見学応援）も、当日はスタンプラリーに参加できます。

## 1. 当日参加者・スタンプラリー参加者

会場で企業ブースを回りながらスタンプを集め、景品と交換していただく参加者向けの説明です。事前登録していない一般来場者だけでなく、事前登録された学生の方もこの流れで会場での参加体験に進みます。

### ご利用の流れ

まず会場に掲示された二次元コード、もしくはスタッフからご案内するURLからスタンプラリー開始ページ（`start.html`）を開きます。事前登録済みの学生の方は、受付でお渡ししたQR名刺、または事前登録時にメールで届いたマイパス（`mypass.html`）のQRを提示して「📷 QRコードを読み取る」から読み取ってください。QR名刺やマイパスをお持ちでない当日参加の方は、「📝 当日参加登録はこちら」から当日参加登録画面（`register.html`）に進み、お名前、大学名、メールアドレスなどをご入力いただいた上で登録を行います。登録が完了するとご自身のマイパスが発行され、以後はマイパスを開けばスタンプラリーへ復帰できます。

登録が終わったら、会場内の各企業ブースをお回りください。各ブースにはNFCタグが設置されているので、対応するスマートフォンをタグにかざしていただくと、スタンプ取得画面（`stamp.html`）が起動して1個スタンプが加算されます。獲得済みのスタンプ数はスタンプ進捗ページ（`progress.html`）でいつでも確認できます。所定の数（既定では15個）に達すると景品交換ボタンが有効化され、当日の景品交換所でスタッフに画面を提示していただくことで景品をお受け取りいただけます。

### よくあるご質問（Q&A）

**Q. QRコードの読み取り画面が真っ黒のままです。**  
ブラウザでのカメラアクセスが許可されていない可能性があります。iOS Safari であれば「設定 → Safari → カメラ → 許可」、Android Chrome であれば「サイト設定 → カメラ → 許可」に変更のうえ、ページを再読み込みしてください。プライベートブラウズモードでもカメラは動作しないケースがあります。

**Q. NFCタグにタッチしてもスタンプ画面が開きません。**  
ご利用のスマートフォンがNFC読み取りに対応している必要があります。iPhone の場合は iPhone XS 以降であれば背面上部でタグを検出できます。Android の場合は端末設定でNFCがONになっていることをご確認ください。それでも反応しない場合は近くのスタッフまでお声掛けください。

**Q. スタンプの進捗が消えてしまいました。**  
ブラウザのCookieが端末で消去された可能性があります。事前登録の方は受付メールに、当日参加の方は登録完了メールに記載されたマイパスURLを再度お開きいただくと、以前のスタンプ状態が復帰します。復帰できない場合は運営スタッフに氏名でお問い合わせください。

**Q. 一度の登録で家族分も参加できますか？**  
1名につき1登録が必要です。お手数ですがお一人ずつ登録をお願いいたします。

**Q. 景品はどこで受け取れますか？**  
規定個数を集めるとスタンプ進捗ページに景品交換ボタンが表示されます。会場の景品交換所でスタッフにその画面をお見せください。

**Q. 事前登録したのに、当日また登録が必要ですか？**  
不要です。事前登録の際にメールでお送りしたマイパスをそのまま開いていただき、QRを読み取ればすぐにスタンプラリーへ参加できます。

## 2. 事前登録する学生（選手・見学応援・出場校エントリー代表）

大会に出場する選手、メカニック、補欠、見学・応援の学生、および学校ごとの代表として出場校エントリーを提出する学生向けの説明です。事前登録は「個人の登録」と「学校単位の登録」の2種類があり、多くの場合、両方をご入力いただくことになります。

### 個人の事前登録（`register-pre.html`）

所属大学からご案内される事前登録URL（末尾に `?event=<イベントID>` が付与されています）をお開きください。ページ上部でご自身の氏名、ふりがな、大学名、学部学科、学年、性別、生年月日、メールアドレス、電話番号をご入力いただきます。大学名の入力欄では入力途中で候補が表示されますので、リストから選択してください。リストにない場合はそのまま自由入力していただいても構いません（新規大学として自動登録されます）。

続いて参加区分を「出場選手（FGクラスドライバー）」「出場選手（女子クラスドライバー）」「補欠ドライバー／メカニック」「見学・応援学生」から選択します。区分を選ぶと、その区分ごとに必要な追加項目（誓約書・免許証・保険証明のアップロード、担当クラス、宿泊・弁当希望など）が現れますので、順にご入力・アップロードください。

大会規則書と誓約書のリンクはフォーム内に配置されていますので、ご確認のうえ同意チェックにチェックを入れてください。SNS掲載への同意、個人情報の取扱いへの同意も併せてお願いいたします。すべての入力を終えて送信すると、ご登録のメールアドレスに受付完了メールが届きます。メール本文にはマイパス（`mypass.html`）のURLが記載されており、大会当日はこのマイパスにあるQRコードを提示していただくことで受付・スタンプラリーへ参加いただけます。スタンプラリーの遊び方は「1. 当日参加者・スタンプラリー参加者」の章をご参照ください。

### 学校単位の出場校エントリー（`register-school.html`）

出場校エントリーは、選手ごとではなく **学校単位で1回だけ** 提出するフォームです。パス発送先や車両入場証枚数を学校でまとめてご登録いただくためのもので、通常は自動車部の主将などが代表として入力します（見学応援学生や、大会当日は参加しない総務担当の学生が入力するケースもあります）。

事務局から案内される出場校エントリーURL（末尾に `?event=<イベントID>`）を開き、大会規則書のリンクを確認して同意チェックを入れます。学校名を入力すると、既に提出済みの学校であれば「この学校は既に提出されています。上書きしますか？」という警告が表示され、上書き同意のチェックを入れなければ送信できないようになっています。上書きした場合、以前の内容は最新のもので置き換えられ、旧承諾書は履歴として保管されます。

続いてエントリー代表者の氏名・電話番号・メールアドレス、入場パスの発送先（名義人・郵便番号・住所・電話番号）、必要な車両入場証の枚数（1〜4枚または不要）、事務局への連絡事項をご入力ください。フォーム内の「学校職員参加承諾書」テンプレートリンクからPDFをダウンロードし、必要事項を記入・押印のうえ、学校顧問または職員の署名を取り付けたPDFを再アップロードしてください。送信すると代表者アドレスに確認メールが届きます。新規登録と上書き更新で件名が変わるため、更新が反映されたことをメール上でご確認いただけます。

### よくあるご質問（Q&A）

**Q. 個人の事前登録と、学校単位の出場校エントリー、両方必要ですか？**  
はい、両方必要です。個人の事前登録は選手・スタッフ全員がそれぞれ提出し、学校単位のエントリーは大学ごとに代表者1名がまとめて提出します。学校単位のエントリーはパスの発送先や入場証枚数を確定させるためのもので、選手が個別に出しても情報が重複するため、必ず代表者1名がまとめて入力してください。

**Q. 参加区分の締切を過ぎたら登録できませんか？**  
運営が管理画面で設定した締切を過ぎた区分は選択できなくなります。締切前でも定員に達した場合など、事務局判断で早期に閉じるケースがあります。締切間際でエラーが表示された場合は事務局までご連絡ください。

**Q. 電話番号や郵便番号の先頭のゼロが消えてしまう気がします。**  
ハイフンあり（例：090-1234-5678、166-0015）／ハイフンなし（例：09012345678、1660015）のどちらでもご入力いただけます。どちらの形式でもシステム側で正しく文字列として保存されますのでご安心ください。

**Q. 出場校エントリーを間違えて送信しました。修正できますか？**  
同じ学校名で再度送信していただければ上書きになります。送信時に「既に提出済みです」の警告が出て、上書き同意チェックを入れることで最新内容に更新されます。個人の事前登録の修正は現状フォームからは行えませんので、事務局までメールでご連絡ください。

**Q. マイパスのURLをなくしてしまいました。**  
事務局までお名前と所属大学をお伝えいただければ再送いたします。

**Q. アップロードするファイルの形式に制限はありますか？**  
PDFまたは画像（JPEG／PNG）で、1ファイル10MB以内を目安にお願いします。スキャン画質は文字が判読できる程度で十分です。

**Q. 承諾書のテンプレートが見当たりません。**  
出場校エントリーフォーム内のアップロード欄にテンプレートへのリンクがあります。表示されない場合はブラウザキャッシュを消して再読み込みするか、事務局までご連絡ください。

**Q. 学校名の候補が表示されません。**  
入力欄に文字を入れると、事務局に登録済みの大学リストから候補が絞り込まれます。まだ登録実績がない大学の場合は候補が出ませんが、そのまま入力していただいて問題ありません（「大学」「大学校」まで含めて入力してください）。

**Q. 出場校エントリー代表として登録した学生も、当日スタンプラリーに参加できますか？**  
はい、参加できます。代表者ご本人が選手・メカニック・見学応援などの立場で会場に来場される場合は、個人の事前登録で発行されたマイパスからスタンプラリーへご参加ください。代表としての情報登録は学校単位の集計にのみ使用されます。

## 3. 出展企業ご担当者

企業としてブース出展いただく際の申込〜当日運用の説明です。

### ご利用の流れ

事務局から案内される出展申込URL（`company-entry.html?event=<イベントID>`）にアクセスします。会社名、略称（当日の来訪学生一覧で表示されます）、代表者名、担当者名、電話番号、メールアドレス、住所、出展内容・PR文、ブースサイズ希望、車両搬入台数、デモ走行の実施有無、必要な人物パス・車両パス枚数、当日の弁当希望数などを順にご入力ください。連絡事項欄には合同出展の相手先やブース配置希望などをご自由に記載できます。送信後、事務局にて内容を確認したうえで受付処理を行い、後日メールで結果をお知らせいたします。

大会当日には、事務局から個別に「来訪学生一覧」ページ（`company.html`）のURLをお渡しします。このページでは、貴社ブースにNFCタッチした学生の氏名、学年、大学名、連絡先などを一覧でご確認いただけます。個別の学生情報カード（`card.html`）へも遷移でき、学生の詳細プロフィールを閲覧できます。閲覧できる期間は大会終了日から2ヶ月後までとなっており、それ以降はアクセスできなくなります。

### よくあるご質問（Q&A）

**Q. 申込内容を修正したい／送信内容を確認したい。**  
恐れ入りますが、企業側での再編集機能は現状ございません。事務局までメールにてご連絡ください。

**Q. 来訪学生一覧のURLがわかりません。**  
事務局から発行済みのメールをご確認ください。届いていない場合、迷惑メールフォルダに振り分けられている可能性があります。それでも見当たらない場合は事務局へご連絡ください。閲覧URLには専用のキーが含まれているため、外部への共有はお控えください。

**Q. 学生の個人情報を保存・持ち出ししてもよいですか？**  
プラットフォーム上の情報は大会の縁組みを目的にご提供しているものです。営業目的等での二次利用については事務局までご相談ください。

**Q. デモ走行の実施にあたって注意事項はありますか？**  
学生を同乗させる場合は、実施企業側の責任で保険加入をお願いしております。フォーム上のデモ走行詳細欄に、走行内容と保険加入状況をご記載ください。

**Q. 出展料の請求・支払方法は？**  
本プラットフォーム内では扱っておりません。事務局からの別途ご請求書に従いお手続きください。

## 4. 運営メンバー（管理者・景品交換スタッフ）

イベント全体の設定、参加者・企業・大学の管理、フォームの公開日時制御などを行う運営スタッフ向けの説明です。中心となるのは管理画面（`admin.html`）の操作で、加えて必要に応じて景品交換ページ（`exchange.html`）を使用することがあります。

### ログインと基本操作

`https://formulagymkhana.github.io/fg-event-platform/app/admin.html` にアクセスし、GASスクリプトプロパティに登録された `ADMIN_KEY` を入力してログインしてください。パスワードを忘れた場合は「パスワードをお忘れですか？」からメールリセット手続きが行えます（事前に GAS で `setAdminRecoveryEmail()` の設定が必要）。

ログイン後、イベント一覧が表示されます。対象イベントを選ぶと、そのイベントのダッシュボードに遷移し、スタンプログ・景品交換履歴・各種統計を確認できます。ダッシュボード上部のナビカードから、企業管理／学生管理／フォーム管理／大学管理／エントリーリスト／受付リストの各ページへ移動できます。

### 主なページと役割

**企業管理**：出展申込フォームからの受付一覧、企業ごとの閲覧URL（`company.html` 用のキー）の発行、CSVによる一括インポートが行えます。未発行キーがある企業は「🔑 未発行キーを一括発行」で一括処理できます。

**学生管理**：事前登録者と当日参加者の一覧を表示します。区分ごとの人数集計、個別修正、当日参加者へのマイパスURL再送などを行います。

**フォーム管理**：3タブ構成（フォーム設定 / メール設定 / 書類URL設定）で、公開開始日時、区分別締切、確認メール文面、大会規則書・誓約書・承諾書のリンク先を設定します。事前登録フォーム／当日参加登録／出場校エントリーの各URLはこのページからコピーできます。

**大学管理**：参加大学の一覧、出場校エントリーの提出状況、承認待ち（自動割当された仮コードの承認）を扱います。仮コード（`0001` 等）は「自動割当（要確認）」タグ付きで表示され、承認するとポケベル方式の正式コードに置き換わり、学生IDも横断的に書き換えられます。

**エントリーリスト**：出走大学の順序編集、女子ペアリング設定、および全エントリーのCSV出力を行います。走行順は「男子A→女子A→男子B→女子B→男子C」の順で自動計算されます。

**受付リスト**：選手受付・応援学生受付・走行順の3タブでCSV出力が可能です。既存のテンプレートXLSXへの貼り付け運用が前提となっています。

**全体設定**：管理者キーの変更、キャッシュのクリア、GAS APIのURL確認が行えます。

### 景品交換ページ（`exchange.html`）について

会場でスタンプラリーの景品を配布する運用を行う場合のみ使用する補助機能です。現状の運用ではほとんど使用しない前提で組まれています。使用する場合は、事務局から発行された景品交換URL（末尾に `?event=<イベントID>` と交換キーを含みます）をスタッフ端末で開き、学生の進捗ページに表示されるQRを読み取って景品を選び、「交換確定」で在庫を減算します。誤操作の取り消しは管理画面（学生管理 → 対象学生 → 交換ログ）から行ってください。交換キーは外部に漏れると不正交換の原因になるため、当日限りでの使用にとどめてください。

### 巻き戻し禁止の設計判断

以下は意図的な仕様のため、コードレビューでバグとして指摘されても復活・厳格化は行わないでください。

- **当日受付コード（WALK_IN_CODE）は撤廃**。`register.html` は誰でもアクセス可能で、コード検証は行いません。会場前提での運用のため利便性を優先しています。
- **イベント判定は日付駆動**。状態は「公開中／公開停止」の2値のみです。開催日内でも `公開停止` を選ぶことで緊急停止が可能ですが、逆に「公開中を必須」とする厳格化は無人運用時の単一障害点になるため導入しません。
- **出場校エントリーは学校名で上書き**。選手交代等の複雑な操作は行わず、シンプルに最新提出で上書きする方式です。旧承諾書はDrive上と履歴列に保管されます。
- **エントリー／受付リストはCSV出力のみ**。PDF/XLSX直接出力は既存テンプレートを崩す恐れがあるため、テンプレートへの貼り付け運用が正式です。

### GAS再デプロイの注意

`docs/gas-patches/api.gs.final.txt` および `admin.gs.final.txt` は GAS 本体のパッチファイルです。フロントの変更だけで済むケースが大半ですが、GASを触った場合は GASエディタへ手動コピーして再デプロイが必要となります。再デプロイ中は数秒間APIが停止するため、稼働中イベントの最中は避け、開催後や早朝など利用者が少ない時間帯を選んでください。

### よくあるご質問（Q&A）

**Q. 管理画面のURLがわからなくなりました。**  
`https://formulagymkhana.github.io/fg-event-platform/app/admin.html` です。ブラウザにブックマーク登録しておくことをおすすめします。

**Q. 管理者キーを忘れました。**  
ログイン画面の「パスワードをお忘れですか？」から復旧メールを送信できます。事前に `setAdminRecoveryEmail("...")` を GAS エディタで実行しておく必要があります。設定していない場合はGASエディタから `resetAdminKey()` を直接実行し、新しいキーを取得してください。

**Q. 新しいイベントを開始したいのですが。**  
イベント一覧画面から「+ 新規イベント作成」を選び、イベントID・イベント名・開始日・終了日・公開状態を入力してください。既定は「公開中」です。作成後はフォーム管理ページで各URLを取得し、関係者に配布してください。

**Q. 電話番号や郵便番号の先頭ゼロが消えているセルがあります。**  
過去に登録された古いデータで、書式設定と書き込み順序の不具合により先頭ゼロが失われたものです。2026-07-24 のパッチ（コミット 5242d22）で新規登録は解消済みですが、既失データは Sheets 上でセルを選択してテキスト書式に変更のうえ再入力する必要があります。

**Q. 承認待ちの大学が消えません。**  
仮コード（`0001`〜）の大学は事務局が正式コードを割当てるまで承認待ちとして残ります。「承認」ボタンを押すと正式コードへの置換と学生ID書き換えが同一トランザクションで行われ、承認待ちから外れます。

**Q. スタンプが誤って加算されました。**  
学生管理ページから対象学生を選び、スタンプログの該当行を削除してください。景品交換済みの場合は交換ログも合わせて調整が必要です。

**Q. フォームが公開されないと連絡がありました。**  
以下を順に確認してください。① イベント状態が「公開中」か（`公開停止`だと全システムが停止）。② フォーム公開開始日時が現在時刻より未来になっていないか。③ 対象区分の締切を過ぎていないか。④ 対象イベントの開催期間内か。

**Q. GASを再デプロイしたのに変更が反映されません。**  
GASエディタの「デプロイ → デプロイを管理 → 編集 → 新バージョン」で再度デプロイし直してください。「新規デプロイ」を選ぶとAPI URLが変わってしまうため必ず「デプロイを管理」から進んでください。加えて `js/config.js` の `API_BASE_URL` が旧URLのままでないかも確認してください。
